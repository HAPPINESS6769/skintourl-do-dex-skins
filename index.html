Por que o jogo mostra “remote image is invalid or not accessible”?

O endereço pode abrir uma página HTML, apontar para um arquivo ainda não publicado ou não estar acessível pela conexão do jogo. Este site verifica resposta HTTP, tipo PNG, integridade e dimensões antes de liberar a cópia. Se a imagem abre no navegador mas o Easy NPC ainda falha, teste a URL alternativa e confira o log do cliente Minecraft. Essa verificação não substitui um teste dentro do seu jogo.

GitHub Pages hospeda a página e os PNGs. Para gravar novos arquivos, o GitHub exige autenticação e acesso ao repositório; não há envio anônimo. Os links permanecem enquanto o arquivo, a conta e a hospedagem forem mantidos.

Publicar com sua conta GitHub

Esta conexão autoriza o envio de skins para . Visitantes podem abrir e copiar os PNGs sem conta.

  1. Abra a criação de token no GitHub.
  2. Em Repository access, escolha somente o repositório deste site.
  3. Em permissões do repositório, habilite Contents → Read and write.
  4. Crie o token e cole no campo abaixo.
Criar token fine-grained no GitHub ↗

O token fica apenas na memória desta aba e é enviado somente à API do GitHub. Não é salvo no site, no navegador ou no repositório. Recarregar a página desconecta.
