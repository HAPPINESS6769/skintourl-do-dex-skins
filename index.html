DO APP PARA A INTERNET

Publique pelo SkinToUrl Do Dex

01

Escolha o PNG

Abra o app no seu computador e adicione uma textura de skin 64 × 64 ou 64 × 32.

02

Conecte o GitHub

Use uma conta com acesso de escrita ao repositório das skins. O token fica somente na sessão local do app.

03

Publique e copie

Clique em Publicar no GitHub e aguarde a verificação. Depois copie a URL pública do PNG.

Esta página exibe as skins públicas; ela não recebe uploads anônimos. Qualquer pessoa com o link pode visualizar os PNGs. Os links dependem da manutenção dos arquivos e da disponibilidade do GitHub Pages. O site ou plugin de destino também precisa aceitar o endereço.
