# SkinToUrl Do Dex — skins públicas

Página estática e PNGs públicos publicados pelo SkinToUrl Do Dex.

Site: https://jocasfodas.github.io/skintourl-do-dex-skins/

Os PNGs em `skins/` usam nomes baseados no SHA-256 do conteúdo. Qualquer pessoa pode abrir os links; novos envios exigem permissão de escrita neste repositório.

O PNG inicial 2258fe98de19ee34ec6c001e8e41fdcad939d73c07f4b99b2a090d84acef9e62.png é uma amostra roxa de verificação (64 × 64), sem dados pessoais.

O aplicativo Windows, seu código Python e suas credenciais não são distribuídos neste repositório.
